# NutriLens — дизайн-система (MASTER)

Источник правды для визуала приложения. Подобрано с помощью скилла
`ui-ux-pro-max` (`.claude/skills/ui-ux-pro-max`, стек `jetpack-compose`).
Код токенов: `app/src/main/java/com/nutrilens/app/ui/theme/`.

## Стиль
Material 3 Expressive + soft premium: тональные поверхности вместо тяжёлых
теней, крупные скругления, градиент бренда только на главных действиях,
пружинная анимация. Иконки — Material Rounded (активные) / Outlined
(неактивные), эмодзи в структурных местах не используются.

## Цвет (`Theme.kt`)
| Роль | Светлая «Ivory» | Тёмная «Emerald Night» |
|---|---|---|
| background | `#F5F6F2` | `#090D0B` |
| surface | `#FFFFFF` | `#111714` |
| primary | `#0A7F5A` | `#3DDC97` |
| secondary (бирюза) | `#0E7490` | `#5EEAD4` |
| tertiary (янтарь, перебор) | `#C2410C` | `#FDBA74` |
| onSurfaceVariant | `#4A5650` | `#A3B0A9` |
| outline (мелкие подписи) | `#667169` | `#85918A` |

Все пары текст/фон ≥ 4.5:1 (WCAG AA). Расширенные токены — `NutriTheme.colors`:
градиенты бренда/предупреждения/ошибки/воды, `hairline`, `glass`, `shadow`.
Макросы — `macroPalette()`: белки синий, жиры янтарный, углеводы фиолетовый.
Экраны не держат hex — только токены.

## Типографика
Одна гарнитура — **Manrope** (400–800, статические TTF, кириллица, ровные цифры).
Дисплей 44/ExtraBold/−1.4 трекинг (калории), заголовок экрана 28/ExtraBold,
тело 14–16/Medium, line-height ≈ 1.45, подписи ≥ 10.5sp.

## Форма и отступы
Скругления: карточки 22–28dp, кнопки 18dp, поля 14dp, чипы — пилюли.
Ритм 4/8dp; поля экрана 20dp; отступ между карточками 14–16dp.
Зоны нажатия ≥ 44–48dp.

## Движение (`Motion.kt`)
- Emphasized decelerate `(0.05, 0.7, 0.1, 1)` — появления; Exit `(0.3, 0, 0.8, 0.15)` — уходы.
- Длительности: 160 / 280 / 420 / 900 мс; выход ≈ 60–70% входа.
- Пружины: `press()` — нажатия, `slide()` — индикаторы, `settle()` — заполнение прогресса.
- Лесенка списков 45 мс/элемент (максимум 8 шагов).
- Вперёд — сдвиг слева направо, назад — обратно; «+» открывается снизу.
- Системное «Удалить анимации» (`LocalReducedMotion`) выключает бесконечные
  и декоративные анимации.

## Компоненты (`ui/CommonUi.kt`)

`TinyLabel`, модификаторы `pressScale`, `softShadow`, `staggeredIn`.
