# NutriLens Android

Нативное Android-приложение для трекинга питания с ИИ-анализом фото еды (Gemini).
Порт веб-версии NutriLens: дневник, отчёты, напоминания, фоновый анализ фото
с уведомлением о результате и самообновления через GitHub Releases.

## Возможности

- **Дневник**: кольцо калорий, макросы, вода, вес, приёмы пищи с фото и разбором по продуктам.
- **ИИ-анализ еды**: фото → КБЖУ (Gemini `gemini-3.1-flash-lite`), поэлементный расчёт
  вес × плотность, фикс дрейфа сумм, уверенность оценки.
- **Фоновый анализ**: приложение можно закрыть — WorkManager доведёт анализ,
  результат придёт системным уведомлением.
- **Отчёт**: неделя/месяц, графики калорий и веса, серия дней, средние показатели.
- **Ассистент**: локальные инсайты (перебор, белок, вода, вечерний приём и т.д.).
- **Напоминания**: завтрак/обед/ужин по расписанию, вода, взвешивание.
- **Самообновления**: проверка GitHub Releases, загрузка APK и установка поверх.

## Сборка

Требуются JDK 21 и Android SDK (API 35).

```bash
./gradlew.bat assembleDebug   # Windows
./gradlew assembleDebug       # Linux/macOS
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

> Путь к JDK задайте в пользовательском `~/.gradle/gradle.properties`
> (`org.gradle.java.home=...`), если системная Java не подходит.

## Настройка ИИ

Ключ Gemini вводится в приложении: Настройки → Нейросеть. Без ключа анализ
недоступен, остальные функции работают офлайн.

## Стек

Kotlin, Jetpack Compose (Material 3), Room, WorkManager, OkHttp,
kotlinx.serialization, Coil, Navigation Compose.
